# Official Oracle OCI documentation

Use Oracle documentation as the primary source. Service offerings, feature availability, limits, and CLI/API behavior change; browse the relevant live page whenever the answer governs an action.

## Exhaustive live service catalog

- [OCI documentation service directory](https://docs.oracle.com/en-us/iaas/Content/services.htm): the authoritative entry point for every currently documented OCI service. Start here for any service not already linked below, then follow that service's overview, configuration, security, operations, limits, and troubleshooting pages.
- [OCI CLI command reference](https://docs.oracle.com/en-us/iaas/tools/oci-cli/latest/oci_cli_docs/): authoritative command groups, flags, and examples across services.
- [OCI REST API reference](https://docs.oracle.com/en-us/iaas/api/): service operations, request fields, response schemas, and lifecycle models when CLI help is insufficient.
- [OCI API errors](https://docs.oracle.com/en-us/iaas/Content/API/References/apierrors.htm): interpret HTTP/API errors before retrying or changing configuration.

## Cross-service foundations

- [OCI CLI configuration and API signing keys](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/sdkconfig.htm): CLI profiles, signing-key authentication, and file permissions.
- [Account and access concepts](https://docs.oracle.com/en-us/iaas/Content/GSG/Concepts/concepts-account.htm): tenancy, home region, regions, OCIDs, and compartments.
- [Working with compartments](https://docs.oracle.com/en-us/iaas/Content/Identity/compartments/Working_with_Compartments.htm): resource placement, hierarchy, access, and lifecycle.
- [IAM security policies](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/iam_security_topic-IAM_Security_Policies.htm): policy syntax and the inspect/read/use/manage permission model.
- [Getting started with policies](https://docs.oracle.com/en-us/iaas/Content/Identity/Concepts/policygetstarted.htm): administrator and least-privilege guidance.
- [Security overview](https://docs.oracle.com/en-us/iaas/Content/Security/Concepts/security_overview.htm): shared security model and security pillars.

## Operations, governance, and architecture

- [Monitoring and observability](https://docs.oracle.com/en-us/iaas/Content/cloud-adoption-framework/monitoring-and-observability.htm): metrics, logs, traces, alarms, events, and operational integration.
- [Service limits](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/overview.htm): tenancy limits, quotas, usage, and limit requests.
- [Limits by service](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/default.htm): current documented default-limit detail and scope per service.
- [Manage service limits best practices](https://docs.oracle.com/en/solutions/oci-best-practices/manage-your-service-limits1.html): capacity planning, quota review, growth, and resiliency considerations.
- [OCI Core Landing Zone](https://docs.oracle.com/en-us/iaas/Content/cloud-adoption-framework/oci-core-landing-zone.htm): tenancy architecture, governance, security, and observability patterns.

## Service-category starting points

These are navigation aids, not a complete service list. For an individual service, use the live service directory above.

- [Compute overview](https://docs.oracle.com/en-us/iaas/Content/Compute/Concepts/computeoverview.htm): instances, shapes, images, capacity, autoscaling, and compute security.
- [Security for core services](https://docs.oracle.com/en-us/iaas/Content/Security/Concepts/security_core_services.htm): networking, storage, and database security configurations.

For any OCI service—whether core infrastructure, networking, storage, database, containers, developer services, integration, analytics, AI, security, observability, management, governance, migration, edge, hybrid, or multicloud—navigate from the OCI documentation service directory and cite the service-specific page that governs the action.
